# Krivian Bakery

Website for Krivian Bakery: big 6 oz chocolate chip cookies sold in packs of 4 (4 for $24, 8 for $45, 12 for $65, max 12 per order).

Plain HTML, CSS and JavaScript with no build step. Hosted on Cloudflare Pages, which redeploys on every push to `main`.

- `index.html`: home page and menu
- `cart.html`: cart
- `billing.html`: checkout (payment not set up yet)
- `cart.js`: cart logic and prices
- `styles.css`: all styles

Preview locally with `node dev-server.js`, then open http://localhost:5173.
